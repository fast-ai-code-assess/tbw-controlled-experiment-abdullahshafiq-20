# Email Validator Task

## Instructions

In this assignment, you will implement a function that validates email addresses according to standard formatting rules.

### Requirements:
- Your function should take a string as input and return a boolean
- It should return `True` for valid email addresses and `False` for invalid ones
- Implementation can use regex, string parsing, or any approach you prefer
- Your solution should handle common edge cases (missing "@", invalid domain format, etc.)

### Testing Your Solution:
1. Implement your solution in `src/solution.py`
2. Run the provided tests with `pytest` to verify your solution
3. All tests should pass for a complete solution

### Evaluation Criteria:
- Functional correctness (does it catch invalid formats?)
- Code simplicity and readability
- Proper handling of edge cases
- Appropriate use of programming patterns
